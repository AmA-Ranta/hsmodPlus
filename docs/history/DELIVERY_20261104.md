## 2. 安装

1. 完全退出炉石与盒子；
2. 解压安装包到任意目录（保持全部文件与 `hsmodPlus.exe` 同级）；
3. 右键 `hsmodPlus.exe` → 以管理员身份运行（manifest 为 `requireAdministrator`）；
4. 「安装维护」确认炉石目录 / `HSAng.exe` 路径 → 点「安装 / 修复插件」；
5. 设置模式与参数 →「应用设置」→「开始任务」。

### 已知技术债（如实说明）

1. `ArenaController\Ui\MainForm.cs` 与 `ArenaBoxBot\ArenaBoxBotPlugin.cs` 仍是巨型文件（历史遗留）；
   本轮已把可判定逻辑抽出为纯策略（`ControllerModeSwitchPolicy`、`ArenaSceneRecoveryPolicy`）并补断言，
   后续应按同一方式继续拆分，而不是继续堆分支。
2. 竞技场在“无进行中轮次”时依赖插件自动回主菜单再进入（本轮新增，随客户端下次启动生效）；
   若客户端停在其它模式界面过久，插件会在 20 秒稳定期后请求回 HUB。
3. 模式切换需要重启客户端（HsMod 会话模式在启动时确定），因此切换耗时约 30–90 秒；
   无对局时会立即执行，有对局时等到本局结束。
