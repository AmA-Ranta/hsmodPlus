# 人工验收入口

本文件只记录当前验收方法。逐轮日志、历史 PASS/FAIL、当时的工具路径统一归档在
[历史人工验收记录](history/TEST_PLAN_MANUAL.md)，不再与当前指南混排。

## 基本规则

- 自动单元测试不能替代真实 UI 验收；实机测试从中控真实点击开始，并保留日志、API 状态及截图。
- 每次用日志偏移、日期、PID 与启动时间绑定本次会话，不能把历史同时间日志当作本次证据。
- 不读取或输入战网密码；人工登录前置条件未满足时应等待。
- 任何部署、模式切换、关闭游戏都必须尊重安全对局边界。故障注入需要另行授权。
- 未实际触发的分支只标“待验证”，不以对象存在、动画或单次日志代替完整正确性证明。

## 必测路径

1. **启动**：应用设置 → 开始 → 官方启动链 → 会话模式确认 → 运行配置回执 → 脚本开启。
2. **卡组**：构筑模式按名称准确选中卡组，找不到时明确失败、不开脚本。
3. **停止/切换**：局中请求必须排队；本局结束后确认停止回执，再按设置退出或切换。
4. **每日计划**：分别验证窗口外等待、到点启动、战网登录等待及登录后恢复、到点局后停止、次日窗口重新启动。
5. **拼装**：脚本关闭时不干预；有有效建议时使用建议；无有效建议且确认处于拼装选择时才随机兜底；不覆盖在途提交。
6. **竞技场**：额度与资源保护、本轮结束停止及重启恢复待处理请求；不把普通发现误判为拼装。
7. **安装**：从完整 ZIP 解压到干净目录验证材料；实际写游戏目录前先退出游戏与盒子。

实机结果写 artifacts，本文件不堆叠现场流水账。稳定结论与问题记录放对应专题文档，历史证据保留在 history。
